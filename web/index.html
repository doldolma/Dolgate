오픈소스 SSH 워크스페이스,
데스크톱에서 모바일로 끊김 없이.

SSH부터 EC2 SSM, tmux, SFTP, 포트 포워딩까지 한 앱에서. 데스크톱에서는 RDP·VNC 원격 화면도 같은 워크스페이스에서 열 수 있습니다. 호스트·키·스니펫은 종단간 암호화(E2EE)로 동기화되고, 동기화 서버도 직접 띄울 수 있습니다.

Features

워크스페이스에 들어 있는 것들

SSH부터 원격 데스크톱, AWS SSM, 컨테이너까지 — 서버 작업의 전 과정을 한 앱에서 다룹니다.

🖥️

SSH / SSM 워크스페이스

SSH, EC2 SSH-over-SSM, SSM shell fallback, ECS Exec, SFTP, 포트 포워딩을 한 앱에서. SSH Agent 인증과 Agent Forwarding 지원.

자세히 →
⌨️

명령어 자동완성

Fig 스펙 기반 자동완성이 원격 세션 안에서 동작합니다. 하위 명령·옵션에 더해 원격 서버의 파일 경로, 서버에서 만들어지는 동적 값, 스니펫까지 이어서 제안합니다.

🤖

AI 어시스턴트

현재 세션의 호스트 정보와 터미널 출력을 바탕으로 질문하고, 조회는 자동·변경은 승인 후 실행. OpenAI 호환 · Claude · Codex 지원.

🖱️

RDP · VNC 원격 데스크톱

데스크톱 앱에서 RDP·VNC 원격 화면을 엽니다. RDP의 여러 모니터를 한 화면에서 보거나 별도 창으로 펼칠 수 있고, Tailscale 직접 연결·RDP over SSM·VNC SSH 터널도 지원합니다.

🔁

E2EE 동기화, self-host로

호스트·시크릿·스니펫을 종단간 암호화로 데스크톱↔모바일 동기화. 동기화 서버(sync-api)는 Docker 한 줄로 직접 띄울 수도 있습니다.

🌐

Tailscale 내장

앱 자체가 tailnet 노드로 참여합니다. Tailscale 클라이언트도 VPN 권한도 없이 tailnet 안의 호스트에 붙고, OS의 라우팅·DNS는 건드리지 않습니다.

Screens

쓰는 모습 그대로

좌우로 넘기면 터미널부터 자동완성·SFTP·원격 데스크톱까지, 앱에서 실제로 보이는 화면입니다.

터미널 워크스페이스 여러 SSH 세션을 탭과 분할로 한 창에 둡니다. 세션 패널에서 자원·프로세스·포트를 그 자리에서 봅니다.

명령 블록 명령마다 종료 상태와 걸린 시간이 붙습니다. 출력만 복사하거나 다시 실행하고, 실패한 명령으로 바로 건너뜁니다.

명령어 자동완성 원격 세션 안에서 하위 명령·옵션은 물론 원격 서버의 파일 경로와 스니펫까지 이어서 제안합니다.

tmux control mode 원격 tmux 의 윈도우가 앱 탭이 되고 pane 이 분할이 됩니다. 나누기·닫기·크기 조절은 UI 로 할 수 있습니다.

AI 어시스턴트 지금 세션의 호스트 정보와 터미널 출력을 근거로 답합니다. 조회는 자동, 변경은 승인한 뒤에 실행합니다.

듀얼 패널 SFTP 왼쪽 로컬·오른쪽 원격을 나란히 두고 옮깁니다. 원격 파일은 내려받지 않고 그 자리에서 편집할 수 있습니다.

포트 포워딩과 터널 Local · Remote · Dynamic 포워딩과 SSM 포워딩, 컨테이너 터널을 한 목록에서 관리합니다. 점프 호스트는 저장한 호스트를 ProxyJump 로 지정하면 끝입니다.

RDP 멀티 모니터 원격 데스크톱의 모니터 여러 대를 한 탭에 나란히 두거나, 로컬 모니터에 하나씩 펼칠 수 있습니다.

Security

비밀번호와 키를 맡길 수 있게

SSH 클라이언트의 기본기는 비밀 관리입니다. Dolgate의 원칙은 단순합니다 — 비밀값은 평문으로 어디에도 남지 않습니다. 자세한 설계는 데이터 보호 문서에 공개되어 있습니다.

✓
OS 보안 저장소에만 저장 비밀번호·개인키·API 키는 macOS Keychain / Windows DPAPI / iOS Keychain / Android Keystore 기반으로 암호화됩니다. 안전한 저장소가 없으면 평문 폴백 없이 저장을 거부합니다.
✓
종단간 암호화(E2EE) 동기화 동기화 데이터는 업로드 전에 기기에서 AES-256-GCM으로 암호화되고, 암호화 키는 이용자가 설정한 동기화 암호로만 열립니다. 관리형 서버든 자체 호스팅이든, 운영자는 원문을 복호화할 수 없습니다.
✓
필요한 것만 동기화 터미널 출력, 세션 녹화, 활동 로그, AI API 키는 서버로 전송되지 않고 기기에만 남습니다.
✓
신뢰를 강요하지 않음 전체 코드가 공개되어 있어 직접 검증할 수 있고, 동기화 서버까지 본인 인프라에 직접 호스팅할 수 있습니다.
Self-host

동기화 서버를 내 손에

브라우저 로그인과 동기화를 담당하는 sync-api는 단일 컨테이너입니다. 띄운 뒤 앱 로그인 화면에서 서버 주소만 바꾸면 됩니다. 

docker run -d --name dolgate-sync-api \
  -p 8080:8080 -v dolgate-sync-api-data:/app/data \
  ghcr.io/doldolma/dolgate-sync-api

상세 설정은 자체 호스팅 가이드를 참고하세요.
