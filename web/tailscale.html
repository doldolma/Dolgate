Built-in Tailscale

SSH 클라이언트에 Tailscale 내장 —
여러 tailnet에 동시 연결

Dolgate는 앱 자체가 tailnet 노드가 됩니다. Tailscale 앱을 설치하지 않고, VPN 프로파일 승인 없이, 여러 Tailscale·Headscale 네트워크의 서버에 한 창에서 접속합니다.

Tailscale 클라이언트는 한 번에 하나의 네트워크에만 붙습니다

서버가 여러 Tailscale 네트워크에 흩어져 있으면, 다른 네트워크의 서버를 볼 때마다 Tailscale에서 계정을 전환해야 합니다. 전환하는 순간 원래 네트워크의 세션은 끊기고, 돌아가려면 또 전환해야 합니다.

Dolgate는 Tailscale의 tsnet으로 앱 안에 네트워크마다 노드를 하나씩 동시에 띄웁니다. 시스템 VPN이 아니므로 하나만 켜야 할 이유가 없고, TUN 디바이스도 관리자 권한도 필요 없습니다.

쓰는 방법

  1. 네트워크 등록 — auth key 또는 브라우저 로그인. Headscale이면 서버 주소를 함께 넣습니다.
  2. 호스트마다 경유할 네트워크 지정 — 지정하지 않은 호스트는 일반 네트워크로 직접 붙습니다.
  3. 접속 — 노드가 올라오는 동안 진행 상황이 보이고, 인증·관리자 승인이 필요하면 그렇게 표시됩니다.

한 번 지정하면 터미널만이 아니라 SFTP·포트 포워딩까지 그 호스트로 향하는 연결이 전부 tailnet을 지나갑니다. 주소는 MagicDNS 짧은 이름, FQDN, tailnet IP 중 무엇이든 됩니다.

이렇게 동작합니다

  • 여러 tailnet 동시 연결 — 네트워크마다 노드 하나, 전환 없이 한 창에서
  • OS 네트워크에 영향 없음 — 시스템 라우팅·DNS를 건드리지 않는 앱 내부 네트워크 스택
  • Headscale 지원 — 컨트롤 플레인 주소만 지정하면 같은 방식으로 등록
  • 모바일 포함 — iOS·Android에서도 같은 방식으로 붙고, 데스크톱에서 등록한 설정은 동기화

등록 절차, 연결 상태, 보안 규칙의 자세한 내용은 Tailscale 가이드 문서에 있습니다.
